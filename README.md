# IT Problems Cheat Sheet

A quick-reference cheat sheet for common IT support problems and their solutions. Built from real-world IT support experience and covers the issues I deal with most often at work

I made one before too it was https://github.com/fawzy-RT/IT-Support-Troubleshooting-Guides  dont forget to read it too

## What's inside

- common IT problems with symptoms, causes, diagnosis, and solution
- Covers network, Windows, printers, applications, AD, email, VPN

## How to use

- Open `it-problems-cheat-sheet.md` to see the full cheat sheet.
- Use `Ctrl+F` to search for the problem.

## Notes

- Always test commands before running them in production.
- Some commands require administrator privileges.
- Don't share passwords, internal hostnames, or sensitive info from outputs
